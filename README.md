# Claude Notch

Статус [Claude Code](https://claude.com/claude-code) в «чёлке» MacBook, как Dynamic Island на iPhone. Видно, что агент делает прямо сейчас, сколько идёт задача и когда он ждёт тебя. Запросы разрешений можно одобрять кнопками прямо в чёлке.

## Что показывает

| Состояние | Как выглядит |
|---|---|
| Думает | пульсирующая ✦ слева от чёлки, таймер справа |
| Выполняет действие | на 2–3 с раскрывается строка: «Выполняет команду», «Читает файл», «Редактирует», «Ищет в коде», «Браузер»… с деталями (команда, имя файла, запрос) |
| Нужно разрешение | карточка «Разрешить команду?» с кнопками **Разрешить** / **Запретить** / «Ответить в приложении» |
| Задаёт вопрос / ждёт одобрения плана | чёлка остаётся раскрытой, пока ты не ответишь |
| Готово | «Готово · за 1:23 · 12 действий», через 4 с прячется |
| Остановлено (Esc) | «Остановлено» сразу после прерывания |
| Ошибка API | «Ошибка» с текстом ошибки |

Работает и в терминальном Claude Code, и во вкладке Code приложения Claude. Если сессий несколько, показывает ту, где событие было последним.

## Требования

- macOS 14 или новее, MacBook с чёлкой. На мониторе без чёлки рисуется «виртуальная» чёлка в строке меню.
- Xcode Command Line Tools: `xcode-select --install` (полный Xcode не нужен).
- Claude Code с поддержкой хуков `PermissionRequest` и `StopFailure`.

## Установка

```bash
git clone <url> ClaudeNotch && cd ClaudeNotch
./build.sh           # собирает, кладёт в ~/Applications и запускает
./install-hooks.sh   # добавляет хуки в ~/.claude/settings.json
```

`install-hooks.sh` не трогает остальные настройки и хуки и сохраняет резервную копию `settings.json.bak-claudenotch`. Повторный запуск ничего не дублирует.

При первом запуске приложение включает автозапуск при входе в систему. Выключить: ✦ в строке меню → «Запускать при входе». Там же есть «Показать демо»: оно проигрывает поддельную сессию с запросом разрешения, на котором можно безопасно понажимать кнопки.

## Как это устроено

```
Claude Code ──hook (stdin JSON)──▶ claude-notch-hook ──Unix socket──▶ ClaudeNotch.app
                     ◀── решение (только для PermissionRequest) ──┘
```

- **`Sources/Hook/main.swift`**: маленький бинарник, который Claude Code запускает на каждое событие. Он пересылает JSON в приложение и печатает ответ, если он есть. Всегда завершается с кодом 0 и молча, даже если приложение не запущено.
- **`Sources/App/Store.swift`**: превращает события хуков в состояние чёлки и отвечает на запросы разрешений.
- **`Sources/App/NotchView.swift`**: SwiftUI-вид: чёрная форма вокруг чёлки, компактный и раскрытый режимы, карточка с кнопками.
- **`Sources/App/TranscriptWatcher.swift`**: на Esc Claude Code не вызывает ни одного хука, поэтому приложение следит за файлом транскрипта сессии и ловит запись `[Request interrupted by user]`.
- **`Sources/App/SocketServer.swift`**: сокет `~/Library/Application Support/ClaudeNotch/notch.sock` с правами доступа только для тебя.

Запрос разрешения ждёт клика до 10 минут. В приложении Claude обычное окно разрешения открывается одновременно с карточкой, и применяется ответ, который пришёл первым. В терминале «Ответить в приложении» возвращает управление обычному диалогу.

## Отладка

Каждое событие, дошедшее до приложения, записывается в `~/Library/Application Support/ClaudeNotch/events.log`.

## Удаление

```bash
./install-hooks.sh --uninstall
pkill -x ClaudeNotch; rm -rf ~/Applications/ClaudeNotch.app
```

Автозапуск снимается вместе с приложением или вручную: Системные настройки → Основные → Объекты входа.
